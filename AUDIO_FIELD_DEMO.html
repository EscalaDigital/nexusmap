🎵 Campo de Audio - NexusMap Plugin

Información: Este es un ejemplo de cómo se ve el campo de audio implementado en el plugin NexusMap. Los usuarios pueden tanto subir archivos de audio como grabar directamente desde su micrófono.
Configuración de Ejemplo:
• Grabación: Habilitada
• Carga de archivos: Habilitada
• Duración máxima: 300 segundos (5 minutos)
• Formatos aceptados: mp3, wav, ogg, flac, m4a, aac

Características Implementadas:

  • ✅ Interfaz intuitiva con iconos descriptivos
  • ✅ Grabación de audio usando MediaRecorder API
  • ✅ Carga de archivos con validación de formato
  • ✅ Preview de audio con reproductor HTML5
  • ✅ Timer de grabación con formato MM:SS
  • ✅ Auto-stop al alcanzar duración máxima
  • ✅ Validaciones en tiempo real
  • ✅ Mensajes de estado y error
  • ✅ Botones de eliminación para ambos tipos
  • ✅ Diseño responsive y moderno
00:00

Cómo funciona:

  1. Para subir un archivo: Haga clic en el área de carga y seleccione un archivo de audio de su dispositivo.
  2. Para grabar audio: Haga clic en "Start Recording", permita el acceso al micrófono y comience a hablar.
  3. Reproducir: Use el reproductor de audio para escuchar el archivo cargado o la grabación.
  4. Eliminar: Use los botones "Remove" para eliminar el audio si es necesario.
  5. Enviar: Una vez satisfecho con el audio, envíe el formulario normalmente.
Estado: El campo de audio está completamente implementado y funcional en el plugin NexusMap. Los archivos se suben al servidor de WordPress y las URLs se almacenan en la base de datos junto con el resto de datos del formulario.
