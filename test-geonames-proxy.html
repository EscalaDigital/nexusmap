🔧 Test de Proxy GeoNames - Solución Mixed Content

Problema resuelto: Mixed Content - Sitio HTTPS haciendo peticiones HTTP a GeoNames

📋 Resumen de la Solución Implementada

🔄 Arquitectura del Proxy

  • Cliente (HTTPS) → Tu servidor WordPress (HTTPS) → GeoNames API (HTTP)
  • El navegador solo ve peticiones HTTPS a tu dominio
  • Tu servidor hace las peticiones HTTP internamente
  • Todo se sirve por HTTPS, resolviendo el Mixed Content

🛠️ Componentes Implementados

1. Handler AJAX en PHP (NM_Ajax_Handlers.php)

// Registrado en constructor: $this->loader->add_action('wp_ajax_nm_geonames_proxy', $this, 'geonames_proxy'); // Método proxy implementado: public function geonames_proxy() { // ✅ Validación de nonce y parámetros // ✅ Lista de endpoints permitidos (seguridad) // ✅ Construcción segura de URLs // ✅ Petición HTTP interna con wp_remote_get() // ✅ Manejo robusto de errores // ✅ Respuesta JSON estructurada }

2. Función auxiliar en JavaScript

function callGeonamesProxy(endpoint, params, timeout = 10000) { const proxyParams = { action: 'nm_geonames_proxy', nonce: nmAdmin.nonce, endpoint: endpoint, ...params }; return $.ajax({ url: nmAdmin.ajax_url, // ✅ HTTPS method: 'GET', data: proxyParams, timeout: timeout, dataType: 'json' }); }

🔒 Características de Seguridad

Validaciones implementadas:

  • Nonce verification - Previene CSRF
  • Endpoints permitidos - Solo countryInfoJSON y childrenJSON
  • Sanitización de parámetros - sanitize_text_field()
  • Validación de respuestas - JSON válido y estructura esperada
  • Timeout configurables - Previene cuelgues del servidor
  • User-Agent personalizado - Identificación correcta

📝 Instrucciones para Prueba Real

Para probar en tu entorno:

  1. Asegúrate de que tu sitio esté cargado por HTTPS
  2. Ve a la página de administración: https://nexus.escaladigital.es/wp-admin/admin.php?page=nm
  3. Añade un campo geográfico al formulario
  4. Ingresa tu usuario GeoNames: gaemir
  5. Haz clic en "Validar Usuario"
  6. Resultado esperado: ✅ Sin errores de Mixed Content

🔍 Cómo verificar que funciona:

  • F12 → Console: No debe aparecer el error de Mixed Content
  • F12 → Network: Todas las peticiones deben ir a tu dominio HTTPS
  • Funcionalidad: Debe cargar países y estructura administrativa

🚨 Troubleshooting

Si sigues viendo errores:

  • Error 500: Verifica que NM_Ajax_Handlers.php se haya guardado correctamente
  • Error nonce: Recarga la página de administración
  • Timeout: GeoNames puede estar lento, es normal
  • Usuario inválido: Verifica que 'gaemir' esté registrado en GeoNames
